# Wind Visualizer

This project was done for the Natural System Simulation's course. It fetches live global wind data and projects a vector field around the globe, these influence the motion of agents that similar to Boids follow pre-set rules to aggregate forces and visualize the wind. Additionally, particle emitters representing contamination can be added showing how contaminants could propagate. This isn't a scientifically accurate representation, but rather demonstrating the concepts viewed in the course.
